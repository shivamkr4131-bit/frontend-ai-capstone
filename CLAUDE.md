# Project Rules

- Use HTML, CSS and JavaScript.
- Keep code clean and readable.
- Commit changes regularly.
- Follow conventional commits.
- Ensure full WCAG accessibility compliance (explicit ARIA attributes, error association, focus indicators, and screen-reader support).
- Prevent XSS vulnerabilities by avoiding `innerHTML` for dynamic user content; use safe DOM methods like `textContent` and `createElement`.
- Implement robust input validation covering edge cases, string trimming, real-time feedback, and dynamic cross-field validation.
